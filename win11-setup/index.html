File Explorer

Turn off folder grouping globally
  1. Open File Explorer and choose any folder.
  2. From the toolbar, select Sort → Group by → None.
  3. Open the three dots (See more) menu and choose Options.
  4. In Folder Options, open the View tab and select Apply to Folders.
  5. Confirm with Yes, then select OK.
